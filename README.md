# 🌡️ Temperature Converter

A simple and responsive Temperature Converter built using HTML, CSS, and JavaScript.

This project allows users to easily convert temperatures between Celsius and Fahrenheit.

## 🚀 Live Demo

https://bashrat365.github.io/temperature-converter/

## ✨ Features

- Convert Celsius to Fahrenheit
- Convert Fahrenheit to Celsius
- Simple and clean user interface
- Responsive design
- Input validation
- Instant conversion result
- Works on desktop and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📖 How It Works

The user enters a temperature and selects the unit.

If Celsius is selected, the temperature is converted to Fahrenheit.

If Fahrenheit is selected, the temperature is converted to Celsius.

The result is then displayed instantly on the screen.
